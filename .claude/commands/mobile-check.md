---
description: モバイルビュー（375/390/430px）で表示崩れ・はみ出しを自動チェックする
---

`stock-order-app.html` を、Playwright MCP を使って以下3つのビューポートで
順番に開き、スクリーンショットを撮ってください。

対象URL:
- ローカル確認: プロジェクトルートで `python -m http.server 8000` を実行し、
  `http://localhost:8000/stock-order-app.html` を開く
- 公開確認（mainマージ後）: GitHub Pagesの公開URL

ビューポート:
1. 375×812
2. 390×844
3. 430×932

各ビューポートについて次を確認してください:
- `document.body.scrollWidth > window.innerWidth` になっていないか（横スクロール発生の検知）
- 主要なボタン・リンクのタップ領域が44×44px以上あるか
- テキストや画像が画面外にはみ出していないか

問題が見つかった場合は、原因箇所（CSS/コンポーネント）を特定し修正案を提示してから、
再度同じ3つのビューポートでスクリーンショットを撮り直して差分を報告してください。

出力は「崩れの有無」「修正した箇所」「再チェック結果」の3行以内の要約＋スクリーンショットのみとし、
詳細なコード全文は貼らないでください。
